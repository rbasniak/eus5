5.2 Forgreninger5.2 Branches

Programmet fra forrige afsnit beregnede et beløb ud fra et antal varer og en enhedspris. Vi så i testen, at programmet også forsøgte at lave beregningen, selvom brugeren indtastede ugyldige input som -10 eller "hej".The program from the previous section calculated an amount based on a number of items and a unit price. We saw in the test that the program also tried to do the calculation even if the user entered invalid inputs like -10 or "hello".

Vi ønsker nu, at de sidste to blokke, beregningen og visningen, kun sker, hvis de indtastede værdier er positive tal. Det gøres i programmering med enforgrening, og det er emnet for dette afsnit.We now want the last two blocks, the calculation and the display, to only happen if the entered values ​​are positive numbers. This is done in programming with a fork, and is the subject of this section.

Bemærk, at der ikke skal ændres noget i designet for at gøre dette.Note that nothing needs to change in the design to do this.

ForgreningBranching

Kontrolstruktur som udfører en række sætninger, hvis en givenbetingelseer sand.Control structure that executes a series of statements if a given condition is true.

BetingelseCondition

Programmet herover gjorde grundlæggende det samme hver gang, uanset input. Det vil vi gerne ændre, så programmets opførsel afhænger af brugerens input. Vi indfører derfor enbetingelsefor, at de to sidste blokke skal køres.The program above did basically the same thing every time, regardless of input. We would like to change that so that the program's behavior depends on the user's input. We therefore introduce a condition that the last two blocks must be run.

I vores program skal de første to blokke stadig hente indholdet af tekstfelterne. Derefter vil vi indsætte envariabel, som kan undersøge, om de indtastede værdier er positive tal. Hvis det er positive tal, skal variablens værdi væresand. Ellers skal værdien værefalsk. En sådan variabel er enboolsk type.In our program, the first two blocks must still retrieve the contents of the text fields. Then we will insert a variable which can examine whether the entered values ​​are positive numbers. If they are positive numbers, the variable's value must be true . Otherwise, the value must be false. Such a variable is of Boolean type.

Et udtryk af boolsk type i en forgrening.An expression of type Boolean in a branch.

Boolsk typeBoolean type

Endatatypesom har værdiensandellerfalsk.A data type that has the value true or false.

In the amount calculator, we make use of standardized blocks, for example, which can retrieve and insert values ​​into text fields. These are examples of the functions that you will learn to use in this section.

FunktionFunction

I koden fra forrige afsnit bliver der brugt fire gule blokke. Det er eksempler på kald (anvendelse) af enfunktion, som andre har stillet til rådighed for os. Fx vil funktionensetNumberændre værdien af et tekstfelt, og to parametre bestemmer, hvor og hvad der ændres:In the code from the previous section, four yellow blocks are used. These are examples of calling (using) a function that others have made available to us. For example, the function setNumber will change the value of a text field, and two parameters determine where and what is changed:

setNumber("beloeb", beloeb);setNumber("beloeb", beloeb);

Vi fortæller altså programmet, at indholdet af tekstfeltetbeloebskal ændres til værdien afvariablen beloeb. Disse to værdier erargumenterfor vores funktionskald. Kald til funktioner kan genkendes på parenteser efter funktionens navn.We therefore tell the program that the contents of the text field amount must be changed to the value of the variable amount. These two values ​​are arguments to our function call. Calls to functions can be recognized by parentheses after the function name.

En funktion kan også have en returværdi. I så fald vil funktionskaldet resultere i en værdi. Det ser vi i kaldet til funktionengetNumber, som både har et argument og en returværdi:A function can also have a return value. In that case, the function call will result in a value. We see this in the call to the getNumber function, which has both an argument and a return value:

var antal = getNumber("antal");var antal = getNumber("antal");

Hvis brugeren har indtastet tallet 14 i tekstfeltetantal, vil funktionskaldet returnere denne værdi:If the user has entered the number 14 in the number text field, the function call will return this value:

var antal = 14;var antal = 14;
